LocPilot v1.1.1 — iOS 虚拟定位 / 路线回放工具（Apple Silicon 原生）
====================================================================

【这是什么】
点一下地图，把 iPhone 的定位传送到那里；也可以在地图上选几个点，
让手机沿规划好的路线按选定速度移动（步行 / 跑步 / 骑行 / 驾车…）。
原生 macOS 应用（SwiftUI + MapKit），iOS 17+ 走 RemoteXPC/DTX 隧道，
免 sudo、无需越狱。

【系统要求】
- Apple Silicon（M 系列）Mac + macOS 26 或更高
- iPhone 需开启开发者模式、用 USB 连接并信任本机（iOS 17+ 默认走 pymobiledevice3）

【安装】
1. 解压 LocPilot-1.1.1-arm64.zip，得到 LocPilot.app
2. 把 LocPilot.app 拖进「应用程序」文件夹

【首次打开】
本版本是 ad-hoc 签名（未做 Apple 公证），首次打开请：
  · 右键点击 LocPilot.app → 打开 → 在弹窗里再点「打开」
  · 或执行一次：xattr -dr com.apple.quarantine /Applications/LocPilot.app

【安装定位引擎（改真机定位必需）】
App 首次运行只会拉起内置后端；要驱动真机，需要 pymobiledevice3：
  菜单栏「引擎 → 安装 / 修复定位引擎…」，按提示安装（约 40MB，无需 sudo）。
没有引擎时仍可用 mock 虚拟设备体验界面。

【使用：传送】
1. 用 USB 连接 iPhone，手机上点「信任此电脑」，并开启开发者模式
2. 点右上角手机图标连接设备（图标变绿表示已连接）
3. 在地图上点任意位置 —— 大头针落下、变绿画勾后，定位即改到那里
4. 点右上角「恢复真实定位」回到真实 GPS

【使用：路线回放】
1. 点底部「路线」进入路线模式
2. 依次点起点、终点（最多还可再加 5 个途经点）
3. 在底部面板选择行进方式：步行 / 跑步 / 自行车 / 电动自行车 / 开车 / 高速
4. 点「开始」——手机沿路线移动，绿色圆点显示当前位置
5. 暂停 / 继续 / 停止；停止后设备停在原地，点「继续」从这个位置接着走

【校验】
shasum -a 256 LocPilot-1.1.1-arm64.zip
结果应与 Release 页里的 SHA-256 一致。
